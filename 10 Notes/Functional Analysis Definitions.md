# Functional Analysis Definitions

> The load-bearing definitions of [[18.102 Functional Analysis]], one line each, grouped by chapter. For context and theorems, follow the chapter links.

## Ch. 1 — [[Topological and Metric Spaces]]

- **Poset / chain / maximal element** — partial order; totally ordered subset; nothing strictly above it. **Zorn**: chains bounded ⇒ maximal element exists
- **Hamel basis** — linearly independent + spans via *finite* sums (exists for every vector space, by Zorn)
- **Topology** — family of "open" sets: contains $\emptyset, X$; closed under arbitrary ∪, finite ∩
- **Hausdorff** — distinct points have disjoint neighborhoods (limits unique)
- **Interior / closure / boundary / dense** — largest open inside / smallest closed containing / edge points / closure is everything
- **Continuous** — preimages of open sets open. **Sequentially continuous** — preserves limits of sequences (equivalent under first countability)
- **Initial topology** — coarsest making a given family of maps continuous (→ product, weak, weak-* topologies)
- **Base / first countable / second countable / separable** — opens generated by unions / countable neighborhood base at each point / countable base / countable dense set
- **Compact** — every open cover has a finite subcover. **Sequentially compact** — every sequence has a convergent subsequence (equivalent in metric spaces)
- **Topological vector space** — Hausdorff + continuous vector operations
- **Metric** — definite, symmetric, triangle inequality. **Cauchy / complete** — internally converging / all Cauchy sequences converge
- **Completion** — dense isometric embedding into a complete space (unique)
- **Hölder conjugates** — $\tfrac1p + \tfrac1q = 1$
- **$\ell^p, \ell^\infty, c_0, c_c$** — $p$-summable / bounded / null / finitely-supported sequences
- **Nowhere dense / meager / residual** — closure has empty interior / countable union of nowhere dense ("small") / complement of meager ("generic")

## Ch. 2 — [[Normed and Banach Spaces]]

- **Norm / seminorm** — homogeneous + triangle + definite / without definiteness
- **Banach space** — complete normed space
- **Schauder basis** — unique *norm-convergent* series representation for every vector
- **Bounded operator** — $\|T\| = \sup \|Tx\|/\|x\| < \infty$ (⇔ continuous)
- **Dual space** $X^*$ — bounded linear functionals; always Banach
- **Sublinear functional** — subadditive + positively homogeneous (Hahn–Banach's dominating gauge)
- **Bidual / canonical embedding / reflexive** — $X^{**}$; $i(x)(f) = f(x)$, always isometric; reflexive = $i$ surjective
- **Closed operator** — graph $\{(x, Tx)\}$ closed; sequentially: $x_n \to x$, $Tx_n \to y$ ⇒ $y = Tx$

## Ch. 3 — [[Measure Theory and the Lebesgue Integral]]

- **σ-algebra** — contains $\emptyset$, closed under complement + countable union
- **Measure** — $\mu(\emptyset) = 0$ + countable additivity on disjoint sets; **null set** — measure 0; **a.e.** — off a null set
- **σ-finite** — space is a countable union of finite-measure pieces
- **Borel σ-algebra** — generated by the open sets
- **Outer measure** — monotone, countably *sub*additive, on all subsets
- **Carathéodory criterion** — $A$ measurable iff it slices every $B$ additively: $\mu^*(B) = \mu^*(B \cap A) + \mu^*(B \setminus A)$
- **Complete measure** — subsets of null sets are measurable
- **Lebesgue measure** — outer measure from open-cuboid covers, Carathéodory-restricted; translation invariant, = volume on cuboids
- **Regular** — inner approximation by compacts, outer by opens
- **Hausdorff measure / dimension** $\mathcal{H}_s$ — diameter$^s$-weighted covers, δ→0; the critical $s$ where $\infty$ drops to $0$
- **Measurable function** — preimages of Borel sets measurable (test $\{f > \alpha\}$)
- **Simple function** — finitely many values: $\sum \lambda_i 1_{A_i}$
- **Integrable** — measurable with $\int |f| \, d\mu < \infty$
- **$L^p(\Omega)$** — $\int |f|^p < \infty$, modulo a.e. equality; **$L^\infty$** — essentially bounded, $\|f\|_\infty = \operatorname{ess\,sup}|f|$
- **Uniformly convex** — distant unit vectors have midpoints well inside the ball ($L^p$, $1<p<\infty$)

## Ch. 4 — [[Dual Spaces and Weak Topologies]]

- **Locally convex space** — topology from a separating family of seminorms
- **Weak topology** $\sigma(X, X^*)$ — coarsest making all of $X^*$ continuous; $x_n \rightharpoonup x$ ⇔ $f(x_n) \to f(x)\ \forall f$
- **Weak-\* topology** $\sigma(X^*, X)$ — coarsest making all evaluations $f \mapsto f(x)$ continuous; $f_n \stackrel{*}{\rightharpoonup} f$ ⇔ pointwise on $X$
- **Schur property** — weak = norm convergence for sequences ($\ell^1$)

## Ch. 5 — [[Hilbert Spaces]]

- **Inner product** — positive definite, conjugate-symmetric, linear in the *second* slot (course convention)
- **Hilbert space** — complete inner product space; norm $\|v\| = \langle v,v\rangle^{1/2}$
- **Parallelogram law** — $\|u{+}v\|^2 + \|u{-}v\|^2 = 2\|u\|^2 + 2\|v\|^2$; holds iff the norm is an inner-product norm (recover via **polarization**)
- **Orthogonal / orthogonal complement** $V^\perp$ — $\langle x,y\rangle = 0$ / everything orthogonal to $V$ (always closed)
- **Orthogonal projection** $P_V$ — closest-point map onto a closed subspace; $H = V \oplus V^\perp$
- **Orthonormal basis** — *maximal* orthonormal set ⇔ dense span ⇔ no nonzero vector ⊥ all
- **Unconditional convergence** — every reordering of the series converges to the same limit
- **Dual operator** $T'$ — $f \mapsto f \circ T$ on duals; **Hilbert adjoint** $T^*$ — $\langle x, Ty\rangle = \langle T^*x, y\rangle$
- **Self-adjoint / unitary / normal** — $T^* = T$ / $T^*T = TT^* = I$ / $T^*T = TT^*$

## Ch. 6 — [[Spectral Theory]]

- **Resolvent set** $\rho(A)$ — $\lambda$ with $(A - \lambda)^{-1} \in BL(X)$; **resolvent** $R_\lambda = (A-\lambda)^{-1}$
- **Spectrum** $\sigma(A) = \mathbb{C} \setminus \rho(A)$ — **point** (not injective: eigenvalues) ⊔ **continuous** (injective, dense range, not surjective) ⊔ **residual** (range not dense)
- **Spectral radius** — $r(A) = \lim \|A^n\|^{1/n} = \max |\sigma(A)|$
- **Numerical range** — $W(T) = \{\langle x, Tx\rangle : \|x\| = 1\}$; $\sigma \subset \overline{W}$
- **Compact operator** — bounded sets → relatively compact images (⇔ weak convergence → norm convergence)
- **Finite rank** — finite-dimensional range
- **Invariant subspace** — closed $M$ with $TM \subset M$
- **Fredholm operator / index** — finite-dim kernel + closed range of finite codimension; index = $\dim\ker - \operatorname{codim}\,\mathrm{range}$ ($T - I$, $T$ compact: index 0)
