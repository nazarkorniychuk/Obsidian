# BERT (2019)

*Full title: "BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding"* (~120,000 citations).

## Summary

Bidirectional transformer **encoder** pre-trained with masked language modeling + next-sentence prediction, then fine-tuned per task with one output layer. Established the pre-train → fine-tune paradigm for NLP.

## Key results

- New SOTA on **11 NLP tasks**: GLUE 80.5 (+7.7 absolute), MultiNLI 86.7%, SQuAD v1.1 F1 93.2, SQuAD v2.0 F1 83.1

## FFN/activation specifics (why this vault cites it)

BERT kept the [[Attention Is All You Need (2017)|Vaswani]] FFN shape — dense, $d_{ff}=4d$ (Base: 768→3072; Large: 1024→4096) — but swapped ReLU for **GELU** (following GPT-1, which first brought GELU into transformers from [[Gaussian Error Linear Units (2016)|Hendrycks & Gimpel 2016]]). BERT's dominance cemented **dense GELU 4×** as the standard transformer FFN until SwiGLU ([[GLU Variants Improve Transformer (2020)]]).
